# 千駄木ちゃんこ祭りアンケート

`index.html` を入口にした、スマートフォン向けのアンケートフォームです。

回答は Google Apps Script のウェブアプリを経由して、指定の Google スプレッドシート（gid=0）へ保存します。Apps Script のソースは `Code.gs` です。

## ファイル

- `index.html`：フォーム本体
- `styles.css`：デザイン
- `app.js`：入力チェックと送信処理
- `thank-you.html`：回答済み表示と壁紙プレゼント
- `thank-you.js`：回答済み判定
- `wallpaper.html`：3つの作品から1デザインを選び、端末別サイズを受け取るページ
- `wallpaper.js`：1デザインを確定し、iPhone・Android・PC版を何度でも保存できる処理
- `wallpaper-maker.html`：非公開で使う壁紙トリミングツール
- `wallpaper-maker.css` / `wallpaper-maker.js`：トリミング画面と画像処理
- `assets/chanko-wallpaper.png`：回答者向け壁紙
- `assets/wallpapers/`：「茜の千駄木」「蒼流の庭」「朱映の杜」それぞれのiPhone・Android・PC版（計9枚）
- `Code.gs`：Google スプレッドシートへの保存処理

`app.js` の `SCRIPT_URL` には、デプロイ後のウェブアプリURLを設定します。

回答完了後はCookieと`localStorage`へ回答済み状態を1年間保存し、同じブラウザからの再回答を止めます。ブラウザのデータを消去した場合、シークレットモード、または別端末からの回答までは識別できません。

壁紙は一度選択すると別デザイン・別端末版へ変更できません。同じ壁紙の再保存は可能です。

## クーポン総括管理・利用店舗

- `management.html`：「千駄木二丁目町会商店街総括管理サイト」の入口。店舗と責任者の登録・編集、発行済み／未使用クーポンの一覧・件数確認、一括無効化を行います。
- `stores.html`：購入者向けの利用可能店舗一覧・地図。実際の店舗が登録されるまでは空欄です。
- `coupon.html`：購入者向けクーポン。受け取った券を同じブラウザの `localStorage` に保存し、次回以降も開けます。別端末や閲覧データ削除後は復元できないため、URLのブックマークやスクリーンショットも勧めてください。
- `ManagementApp.html`・`StoresApp.html`・`coupon-wallet-app.html`：Apps Script に同名の HTML ファイルとして配置する画面本体です。

総括管理サイトの認証は既存の店舗用 `admin` とは別です。Apps Script の「プロジェクトの設定」→「スクリプト プロパティ」に `MANAGER_PASSWORD_TEMP` を追加し、総括管理専用の強いパスワードを設定してください。管理者IDは `manager` です。初回ログイン成功時、サーバーが SHA-256 ハッシュの `MANAGER_PASSWORD_SHA256` を保存し、平文の一時プロパティを削除します。パスワードをコードや GitHub に書かないでください。設定するまでは管理画面へログインできません。

店舗登録時は店名・責任者を入力します。所在地、緯度、経度をそろえて「公開」にすると購入者向けの地図に表示されます。責任者名は公開されません。登録データはスプレッドシートの `加盟店` シートに保存します。

「全件無効化」は、画面に表示された時点の有効期限内・未使用券だけを一括で `無効` にします。実際に購入者へ渡したかどうかは記録されていないため、未配布の発行済み券も対象です。確認画面から実行までに対象券が変わった場合は処理を中止します。クーポン行は削除せず、店舗側の確認・利用処理では `無効` 券を拒否します。取消し機能はありません。

操作時は `クーポン操作履歴` シートへ券IDごとの開始・完了（または要確認）の履歴を追記します。操作ID、日時、操作アカウント、割引額、変更前後の状態も記録し、過去行を書き換えません。管理画面には直近100行を閲覧専用で表示します。Apps Script エディタで `setupCouponAuditProtection` を一度実行すると、既存の6列・既存行を残したまま追加列を作り、履歴シートを保護できます。保護の設定に失敗した場合、一括無効化は実行しません。

Google スプレッドシートの保護は通常の共同編集者による編集を制限するものです。ファイル所有者とスクリプト実行者まで編集不能にはできません。厳格な改ざん防止が必要な場合は、所有者権限の管理や別保存先へのバックアップも必要です。`クーポンDB` をシート上で直接変更した操作は、このサイトの操作履歴には残らないため、元シートの編集権限も限定してください。また、管理アカウントを複数人で共有すると、履歴の操作アカウントだけでは実際の操作人物を識別できません。
